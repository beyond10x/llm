## Close

Decisions taken during the wave by the implementor, inside the approved design:

| Decision | Why |
| --- | --- |
| `anthropic_beta` holds at most 32 distinct names of 1 to 128 `[A-Za-z0-9._-]`, checked by `TurnRequest::validate` | a header value from a client is bounded like every other identifier the turn carries |
| the Messages decoder reads the header through a second entry point, `decode_request_with_headers`; `decode_request` is unchanged | a gateway that passes no headers keeps its behaviour, byte for byte |
| the subscription OAuth beta and the turn's betas share one `anthropic-beta` header, OAuth first, each name once | one header line; the line both recorded oauth-beta mutations replace stays, and both still die on the case lane |
| the four new header refusals are listed `unaimed` in `docs/verification/messages-falsification.json` | no mutation was aimed at them; `tests/anthropic_beta.rs` holds three by name |
| a container refresh runs on its own task under the source's own cancel, which `Drop` fires | a caller that cancels its wait must not cancel the fetch other callers wait on |
| `ContainerCredentials::refreshing` is public | the conformance adapter and the tests count requests only once a background refresh has landed |
| `task docs-generate` ran on `impl/bedrock-followups` before the merge | the wave branch then holds merges only |
