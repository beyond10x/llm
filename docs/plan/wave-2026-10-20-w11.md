### The evidence for unit 3

Anthropic's API reference (`platform.claude.com/docs/en/api/messages.md`, fetched 2026-10-20 for
0.8.1, lines 4119-4141): "Total input tokens in a request is the summation of `input_tokens`,
`cache_creation_input_tokens`, and `cache_read_input_tokens`"; `cache_creation_input_tokens` is
"number or null"; `cache_creation` is the breakdown by TTL, `ephemeral_1h_input_tokens` and
`ephemeral_5m_input_tokens`, each "default: 0". llm already reads that breakdown and refuses a
non-zero one-hour count (`crates/llm-messages/src/usage.rs:46-65`). So the derivation rests on a
documented contract, not on an assumed zero. The only upstream known to omit the total is the
Harness spike's Messages emulator; whether it sends the breakdown is not known, and the unit's
report says whether the derivation reaches it.

## Close

Decisions taken during the wave, by the coordinator inside the approved design (each recorded on
its story):

| Decision | Why |
| --- | --- |
| `AnonymousResolver` refuses as `Missing`, not `InvalidReference` | exported, it can be handed to a credentialed binding; `Missing` stops the run as `unauthorized`, `InvalidReference` fell back |
| the Tokio check also runs before each per-event deadline, through one per-poll guard | a turn moved out of its runtime mid-stream panicked; the docs are now true |
| the runtime refusal names both ways out | routing runs and `call_tool` are not a `Model`, so `b10x-llm-blocking` cannot run them |
| a later reported cache-write count may raise the derived one, never lower it | the count is cumulative; the same pair in one event was already refused |
| input into a running turn stays not offered; the reason corrected | OpenAI documents Responses steering over WebSocket mode; llm's clients are HTTP with SSE; filed as `story:responses-websocket-steering` |
| the cancel-then-continue pattern answers every open tool call first | every client refuses a request with an unanswered call |
| llama-server's eight unread `timings` fields are accepted, shape-checked and documented | the `UNCONSUMED` precedent of `b10x-llm-messages`; refusing them would refuse every llama-server turn |
| a chunk refused while its report is read leaves the evidence as it was | a refused contradiction still reported a count it rejected |
