## Outcome

Deliver core, three protocols, API and caller-managed subscription access, injected secret resolution, TOML routes, opt-in fallback, cost accounting/limits, Runpod/Modal and an authenticated translating gateway before any consumer migration.

## Sequence

The current repository is a planning scaffold only. story:foundation-qualified is the external adoption prerequisite. Connectors secret custody is a later adapter and does not block the first milestone. Consumers retain their own migration artifacts.
