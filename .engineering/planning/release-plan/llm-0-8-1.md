## Authorization and scope

Approved on 2026-10-20 by session `b10x-chef-orchestrator` (formerly `adr-changes`) under the
owner's standing grant for work implementing Atlas ADRs 0096 to 0101: a release through the
repository's own process when another repository needs to pin it. Live Messages turns through
Harness 0.15.0 on llm 0.8.0 fail with "Messages field is outside the declared subset:
message_start.message.container" (Harness's cutover onto llm, ADR 0097); Harness and the
applications on it pin this release. llm 0.8.1 carries that fix alone, cut from tag 0.8.0; wave
2026-10-20-w10 follows as 0.8.2. The approval covers the release pull request and its merge, the
tag `0.8.1` and the GitHub Release `LLM 0.8.1`; no registry publishing and nothing in other
repositories.

## Execution

Branch `release/0.8.1` from `main` at tag 0.8.0 with two commits, to save one CI round on a live
failure: the fix, then `release: LLM 0.8.1`, which sets the workspace version and `Cargo.lock`,
dates the CHANGELOG section, moves README.md's status line and dependency example, the
`## Status at` heading of `docs/implementation-status.md` and the `source` line of
`website/docs/index.md`, and runs `task docs-generate`. Bot pull request, merged when `Gate` and
`Shared source gates` are green. Tag the merge commit `0.8.1` and publish the GitHub Release
`LLM 0.8.1` with the changelog notes, both as the bot. No binary assets.

## Completion evidence

The tag resolves to the release merge commit; `Gate`, `Shared source gates` and `Documentation
validation` are green on it; the GitHub Release names 0.8.1.
