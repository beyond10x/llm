## Authorization and scope

Source releases of this repository are authorized when merged work is green on `main`.
Release 0.4.0 contains story:catalog-model-port from PR #26: the new `b10x-llm-models` crate,
the `llm.models` ESS domain and the move to ESS 0.56.0. It adds no serving capability and makes no
live provider qualification claim.

## Execution

Prepare release/0.4.0 from main 41285def; set the workspace version and lockfile, date the
changelog, move the status lines and regenerate documentation. Run the package gates of the
touched crates, publish a bot release PR, merge after required checks pass. Tag the merge commit
0.4.0 and publish GitHub Release LLM 0.4.0 with the changelog notes. No binary assets.

The tag resolves to the release merge commit; Gate, Documentation validation and Shared source
gates are green on it; the GitHub Release names 0.4.0. Documentation publication stays
asynchronous; consumers adopt the tag in their own changes.
