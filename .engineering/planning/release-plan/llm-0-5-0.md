## Authorization and scope

Source releases of this repository are authorized when merged work is green on `main`.
Release 0.5.0 contains story:runpod-provider-description from PR #28: the
`llm.provider-description/1` format in `b10x-llm-providers`, Runpod's shipped description and the
`llm.providers.Describe` ESS command with 21 conformance scenarios. It adds no serving capability,
makes no network call and makes no live Runpod qualification claim. llm-gateway's Runpod transport
and key-file stories adopt the tag in their own changes.

## Execution

Prepare release/0.5.0 from main after PR #28; set the workspace version and lockfile, date the
changelog, move the status lines and regenerate documentation. Run the package gates of the
touched crates, publish a bot release PR, merge after required checks pass. Tag the merge commit
0.5.0 and publish GitHub Release LLM 0.5.0 with the changelog notes. No binary assets.

## Completion evidence

The tag resolves to the release merge commit; Gate, Documentation validation and Shared source
gates are green on it; the GitHub Release names 0.5.0. Documentation publication stays
asynchronous; consumers adopt the tag in their own changes.
