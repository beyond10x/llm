## Authorization and scope

The owner asked for the `llm` command in session llm on 2026-10-23 (`llm infer -m <model>`,
`llm model list`, a routes file at `~/.b10x/llm.toml`, Bedrock routes included) and said "do it".
llm 0.12.0 carries story:llm-command (wave 2026-10-23-w16): the crate `llm-cli` and its `llm`
binary, `Routes` resolvers that skip an endpoint whose credential source cannot be built, and
Kubernetes projected-volume container tokens in `llm-credentials`. The approval covers the release
branch, its pull request, the fast-forward of `main` to its green head, the tag `0.12.0` and the
GitHub Release `LLM 0.12.0`; no registry publishing and nothing in other repositories.

`release: LLM 0.12.0` as in 0.11.0: workspace version and `Cargo.lock`, the dated CHANGELOG
