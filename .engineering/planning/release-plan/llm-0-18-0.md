## Version

`Error::refusal`, `Error::with_refusal`, `llm_http::RefusalRule` and
`HttpClient::with_refusal_rule`. The new public field on `Error` breaks a struct literal of
`Error` outside llm, so the CHANGELOG marks it Breaking and the minor version moves: 0.18.0.
