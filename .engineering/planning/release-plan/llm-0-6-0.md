## Authorization and scope

The operator approved a plan on 2026-10-16 that lists this release: llm 0.6.0 carries
story:routes-document, story:responses-ingress-encoder and story:messages-ingress-encoder (epic:routes-and-ingress),
merged from wave 2026-10-16-w07. The plan authorizes the wave's commits, the bot pushes, the wave
pull request and its merge, the release pull request and its merge, the tag `0.6.0` and the GitHub
Release `LLM 0.6.0`; nothing else.

## Execution

After the wave merges into `main`, branch `release/0.6.0` from `main`; one commit `release: LLM
0.6.0` that sets the workspace version and `Cargo.lock`, dates the CHANGELOG section, moves README.md's
status line, the `## Status at` heading of `docs/implementation-status.md` and the `source` line of
`website/docs/index.md`, then runs `task docs-generate`. Bot pull request, merged when `Gate` and
`Shared source gates` are green. Tag the merge commit `0.6.0` and publish the GitHub Release `LLM
0.6.0` with the changelog notes, both as the bot. No binary assets.

## Completion evidence

The tag resolves to the release merge commit; `Gate`, `Shared source gates` and `Documentation
validation` are green on it; the GitHub Release names 0.6.0. Documentation publication stays
asynchronous.
