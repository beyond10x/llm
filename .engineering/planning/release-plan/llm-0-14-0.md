## Authorization and scope

The owner asked for this in session on 2026-10-23 and answered "do it" to the story, the wave and
the 0.14.0 release (`approval-record:bedrock-credential-process-2026-10-23`). llm 0.14.0 carries
story:bedrock-credential-process: a Bedrock endpoint that gets its keys from an AWS
`credential_process` command (`aws-process`), held in memory and refreshed before they expire,
with command execution opt-in by cargo feature and by the caller. The approval covers the release
branch, its pull request, the fast-forward of `main` to its green head, the tag `0.14.0` and the
GitHub Release `LLM 0.14.0`; no registry publishing and nothing in other repositories.
