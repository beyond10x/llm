The site ships no search. The navbar holds the title, Documentation, Crates, Status, GitHub and the
theme toggle, and no search box on any of the 26 pages, at either gating viewport, in either theme.
The adapter lists search as always visible, so gate 2 fails on every page, and gate 5's "Tab reaches
search" fails with it.

Effect: a reader with a term (`exit codes`, `retried`) has to guess the page. The screen-only user
still reaches every task through the navbar and the sidebar, at 8 or 9 actions for four of the five
tasks (`ux/rounds/R-01/report.md`): from the home page it finds no link that matches, scrolls to the
end, and falls back to the Documentation hub link.

Frequency 26 of 26 pages. Cost M (a dependency, its config and a contrast fix).

Fix direction (one line): a local search index built with the site, no external service, in the navbar.

Severity S2: a hard gate fails on every page; no task is blocked.
