`/llm/search`, the full results page of `@easyops-cn/docusaurus-search-local` (added for UXF-001),
renders its query input with a hard-coded `autoFocus`. Focus starts in the input, so the first Tab
moves past it instead of to "Skip to main content", at both gating viewports. Every other check
passes on the page.

Effect: a keyboard user who opens the results page lands in the query box, which is what the page is
for. The skip link is reachable with Shift+Tab. Nothing is blocked.

Frequency 1 of 27 pages. Cost S. Priority 1 × 0.04 × 1 ÷ 1 = 0.04, the lowest of the round.

Left open in R-01: the fix wraps the plugin's `SearchPage` theme component (or adds an upstream
option to turn `autoFocus` off), a change to a third-party component this round does not take. The
waiver covers only this page's skip-link check.

Fix direction (one line): wrap `SearchPage` so focus starts at the top of the page, then drop this waiver.

Severity S3: one page, one keyboard check, the page's own purpose served.
